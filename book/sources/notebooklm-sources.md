# NotebookLM sources: 3 notebooks

Use these lists to build three NotebookLM notebooks. Each list goes from **Zero** (start here) to **Expert** (last).

- Every URL below returned **HTTP 200** in a link check on 5 Oct 2026.
- Everything is **free and legal**:
  - **Open** means the content has an open licence (for example Creative Commons), so you can reuse it.
  - **Free to read** means you can read or watch it for free, but the owner keeps the copyright. Use it for personal study only.
- **NotebookLM limits (confirmed on support.google.com/notebooklm, Oct 2026):** a free account can add **up to 50 sources per notebook**. Each source can be up to **500,000 words or 200 MB**. NotebookLM accepts PDF, Markdown, TXT, Word (docx), PowerPoint (pptx), CSV, ePub, images, audio files (such as MP3 and WAV), Google Docs/Slides/Sheets, copied text, **web URLs** and **YouTube URLs of public videos**. Limits can change, so check the current limit in NotebookLM. The help pages now call the product "Gemini Notebook".
- **YouTube tip:** NotebookLM reads **one public video URL** at a time. A **channel** or **playlist** link will not work as one source. Open the channel or playlist, pick 2-5 videos for the topic you are studying, and add each video URL on its own.
- Our own PDFs come first. They are written for you, so NotebookLM should treat them as the main source.
